## 1.3.1 무역금융·핀테크 AI 트렌드와 미수금 방지 사례 {#m131}

1교시 · #15–#19 · 용어 카드 1

- 물류에서 가장 비싼 구간은 고객에게 닿는 **마지막 1마일**입니다. AI 프로젝트도 **마지막 1미터 — 현업의 실제 문제와 업무 흐름**에서 실패합니다.
- <span class="chip chip--public">[공개 사례 · RAND 2024]</span> "일부 추정에 따르면 AI 프로젝트의 80% 이상이 실패"(RAND가 인용한 추정). RAND가 꼽은 다섯 가지 근본 원인 중 **첫째는 해결할 문제를 잘못 이해·전달한 것, 셋째는 사용자의 실제 문제보다 최신 기술에 집중한 것**입니다.
- 트렌드의 두 축은 **에이전틱 AI**와 **버티컬 AI**입니다. 3년 사이 쓰는 방식이 '대화 → 추론 → 도구 → 에이전트'로 바뀌었습니다 — 그래서 도구는 이름이 아니라 **일 유형**으로 고릅니다.
- 무역금융에서 AI가 실제로 하는 일(아래 표)과, 무역업계의 간극 — **'AI가 필요하다' 78.0% vs '생산성 향상 수준까지 쓴다' 16.9%**(한국무역협회 트레이드 포커스 11호, 2025-06 · 2025-02 설문 396개사).

## 1.3.2 2026 AI 지형도와 도구 선택 {#m132}

1교시 · #20–#22 · 띠: AI 리터러시 · 멀티모달 · 딥 리서치

- 모델 이름은 외우지 말고 **'어디에 강한가'**만 봅니다 — OpenAI GPT(범용·웹 검색·데이터 분석) · Anthropic Claude(긴 문서·코드 실행·파일 생성) · Google Gemini(긴 PDF·멀티모달·문서 근거 Q&A, Gemini Notebook) · 국산·오픈 모델(사내 설치·데이터 반출 제한). 모델과 무료 한도는 자주 바뀝니다(2026-09-26 확인, 개강 직전 다시 확인).
- 도구는 **일 유형**으로 고릅니다.

| 하고 싶은 일 | 고르는 기준 | 예시 도구 |
|---|---|---|
| 두꺼운 PDF·보고서 읽기 | 문서를 통째로 넣을 수 있는가 | Gemini, Claude |
| 웹에서 사실 확인·조사 | 검색 도구가 붙고 출처를 주는가 | ChatGPT 검색·딥 리서치, Claude 웹 검색, Perplexity |
| 표·엑셀 분석 | 코드를 실행하고 보여 주는가 | ChatGPT 데이터 분석, Claude, Colab |
| 여러 문서 근거 Q&A | 답마다 인용이 붙는가 | Gemini Notebook |

## 1.3.3 LLM 원리: 토큰·컨텍스트·확률·할루시네이션 {#m133}

2교시 · #23–#27 · 용어 카드 2 · 3 · 4 · 5

- **LLM은 다음에 올 토큰의 확률로 글을 잇습니다** — 유창함 ≠ 사실. 데이터베이스처럼 사실을 찾아오는 것이 아니므로, 사실 확인은 근거·인용으로 합니다.
- <span class="chip chip--f">[기초 F1]</span> **토큰**은 요금과 한도의 단위이고, 같은 뜻도 언어마다 개수가 다릅니다(예: '수출 대금을 안전하게 받으려면 신용장이 필요하다' 15토큰, 같은 뜻 영어 문장 13토큰 — o200k_base 기준 예시). **컨텍스트 창**은 작업 책상입니다: 지시문 + 올린 파일 + 대화 기록 + 도구 결과가 넘치면 앞부분부터 놓칩니다 → **문서 1개 = 새 채팅 1개**.
- **할루시네이션**은 최신·유료 모델에서도 줄어들 뿐 없어지지 않습니다: 근거 주기 · 인용 요구 · 모르면 비우기 · 숫자는 다시 계산. 잘못된 전제를 그대로 받아 답하는지도 봅니다(예: 'UCP 600에서 서류 제시기간을 선적 후 30일로 정한 조항은?' — 실제는 21일, 제14조 c항).
- 고르는 순서: **기본 모델로 시작 → 틀리거나 조건이 복잡하면 추론 모델 → 같은 여러 단계를 반복하면 에이전트**. 되돌릴 수 없는 일(발송·삭제·한도 변경)에는 사람 승인을 둡니다.

## 1.3.6 AI로 보고서·데이터 읽고 검증하기 {#m136}

- **ADA(코드를 실행하는 데이터 분석)**: 질문 → 코드 작성 → 실행 → 표·차트 → 해석. ChatGPT에만 있는 기능이 아닙니다 — Claude·Gemini도 코드를 실행합니다. 핵심 한 줄은 **"사용한 코드와 계산식을 보여 줘"**.

- **숫자 검증 4단계 라벨** — 숫자를 받을 때 위치(쪽·조항)를 같이 받습니다.

## 1.3.8 [기초 F1] AI 서비스는 어디서 돌아가나 + 데이터 위생 {#m138}

4교시 첫 15분 · #45–#47 · 용어 카드 14 · 15 · 띠: 개인정보·합성 데이터 · 자세히: [기초 지식 F1](../foundations/f1.md)

- **AI 대화창 = 클라이언트, 답을 만드는 곳 = AI 회사 서버** → 올린 파일은 회사 밖으로 나갑니다. 민감할수록 클라우드 → 온프레미스 → 망분리(내부망 전용 소형 모델) 쪽으로 갑니다.
- **CSV는 글자만 있는 표, XLSX는 서식·수식·여러 시트가 있는 파일**입니다. 한글이 깨지면 인코딩 불일치(UTF-8 vs CP949) — **[데이터] → [텍스트/CSV에서] → 파일 원본 '65001: 유니코드(UTF-8)'**로 다시 엽니다. '1,234'·'30days'처럼 숫자처럼 보이는 글자는 합계·피벗에서 조용히 빠집니다(계획서: 텍스트 vs 숫자 불일치).
- **데이터 위생 5원칙 — 'AI 대화창은 외부 채널이다'**
    1. 기본은 합성 데이터 — 실데이터는 익명화 후
    2. 무료 AI·무료 API에 실데이터 금지 — Gemini 무료 API는 사람 검토 대상
    3. 담당자 이름·이메일·계좌는 지운다(개인정보) — 법인 재무 숫자는 개인정보가 아니다
    4. 비밀번호·키·계좌를 대화창에 붙여넣지 않는다
    5. 결과는 검증 후 사용, 출처 표기

## 1.3.9 바이어 금융현안 정의와 AI 도입 ① {#m139}

8교시 · #57–#61 · 용어 카드 16

- **AI 도입은 구매가 아니라 과업 선정입니다.** 도구가 아니라 '어떤 일을, 어떤 데이터로, 무엇으로 성공을 재는가'가 먼저입니다. <span class="chip chip--public">[공개 사례 · RAND 2024]</span> 근본 원인 첫째는 해결할 문제를 잘못 이해·전달한 것, 둘째는 필요한 데이터 부족 · <span class="chip chip--public">[공개 사례 · Gartner 2025-06-25]</span> 2027년 말까지 에이전틱 AI 프로젝트의 40% 이상이 취소될 것(전망) — 비용 증가 · 불분명한 비즈니스 가치 · 부적절한 리스크 통제. <span class="chip chip--field">[현장 사례 · 익명]</span> 전사 도입 뒤에도 실제로 쓰는 직원은 일부에 그친 회사가 있습니다(1개사 관찰).
- **AX**는 업무 흐름을 AI 전제로 다시 짜는 일이고, **PoC**는 작은 범위로 '되는지' 확인하는 실험입니다: PoC → 파일럿 → 확산, 단계마다 멈출 기준(킬 게이트)을 먼저 정합니다.
- **AX 문제 정의 캔버스 7칸** — 1 업무 · 2 현재 방식 · 3 불편·위험(무엇을 놓치면 비싼가) · 4 데이터 · 5 AI가 할 일 · 6 사람이 할 결정 · 7 성공 지표(전 → 후) — 와 **과업 선정 3기준**(즉시 효과 · KPI 직결 · 추가 인프라 불필요, 각 1–5점). 세 점수가 모두 높은 과업이 첫 PoC 후보입니다.
- **AI 네이티브 협업 4요소**: 규칙서(우리 팀 AI 사용 규칙 1장) · 명세(AI에게 맡길 일: 입력·출력·완료 기준) · 검증(원본 대조 · 다른 AI로 교차 검토 · 설명할 수 있어야 제출) · 기록(결정 로그 · 버전). 2일차 8교시에 전원이 GitHub에 첫 커밋을 하고, 본편은 5일차입니다.
