### 1.4 실습 개요 {#practice-overview}

> o 1일차 : 마우스 클릭과 생성형 AI 툴을 활용한 해외 재무제표 해석 및 채권 데이터 시각화

| 실습배경(원문) | 실습목표(원문) |
|---|---|
| o 우리 제품을 해외에 수출할 때 어떤 바이어가 재무적으로 위험한지 실무자의 직관이나 기존 거래 관행에만 의존하여 여신을 무리하게 제공하는 리스크 존재 | o 생성형 AI를 활용한 글로벌 무역 금융 트렌드 분석 기법을 배우고 외국어 재무 데이터 조사에 대한 심리적 장벽 해소 |
| o 방대한 해외 기업 보고서와 글로벌 신용조사 데이터 속에서 진짜 유의미한 재무 위험 징후를 사람이 일일이 읽고 찾는 데 막대한 시간 손실 발생 | o 챗GPT의 파일 업로드 분석 기능(Advanced Data Analysis)을 활용해 해외 기업 보고서 줄글에서 핵심 재무 위험 징후를 도출하는 역량 습득 |
| o 코딩을 모르는 초급 실무자가 챗GPT의 데이터 분석 기능을 활용해 복잡한 외국어 재무제표를 (…) 해석하고 리스크 현안을 과학적으로 도출할 필요성 대두 \* | o 노코딩 시각화 도구를 사용해 복잡한 대금 회수 지연 현황을 한눈에 볼 수 있는 그래프와 차트로 직접 그려내는 능력 배양 |
| | o 자사 수출 품목과 타겟 바이어의 대금 결제 방식(L/C, T/T)을 결합하여 실제 현업에서 해결할 핵심 금융 리스크 현안을 명확히 정의 |

\* 원문의 '1초 만에'는 생략했습니다 — 실제로는 업로드·실행·검증에 몇 분이 걸리고, 오늘의 목표는 **검증까지**입니다.
실습 특징: 가상 회사 한빛정밀 + 실제 SEC 공시 · 3트랙(Basic 전원 완주) · AI 숫자는 원문·엑셀로 검산.

| `03_EDA` | ① P1-3 오염 목록 ② P1-4 요약표·코드 · AI 숫자(B65–B67) ③ AI 숫자 vs 엑셀 숫자 대조 ④ 인사이트 | [Step 4](lab-a.md#step4) · [Step 6](lab-b.md#step6) |
| `04_피벗` | 피벗①(A22) + 100% 누적 막대 · 피벗②(A42) · (다 했으면) 피벗③(A62) — **오늘 결과물 'EDA 시각화 차트'** | [Step 5](lab-b.md#step5) |

## 1.9 산출물과 제출 {#submit}

> o 1일차 결과물: 타겟 바이어 기본 재무 지표(유동비율, DSO 등) 변수 정의서 및 EDA 시각화 차트

| 항목 | 작성 내용 | 시트 |

| EDA 시각화 차트 | 피벗①(결제방식 × 연체 구간) + 100% 누적 막대 · 피벗②(국가별) | `04_피벗` |
| EDA 기록 | 오염 목록 · AI vs 엑셀 대조 · 인사이트 | `03_EDA` |
| 보고서 해석 | 위험 신호 표 · 비율 검증 | `01` · `02` |
| 금융 현안 | 결제방식별 현안 정의서 · AX 캔버스 | `06` · `07` |

**제출 파일 하나**: 템플릿에 오늘 결과를 모은 뒤 `d1_end_eda__T{조}-{번호}.xlsx` 이름으로 저장합니다.
번호는 두 자리로 씁니다. 예: 2조 7번 → `d1_end_eda__T2-07.xlsx` (밑줄 두 개, 대문자 T, 하이픈)

1. 엑셀에서 **파일** → **다른 이름으로 저장** → **찾아보기**를 누릅니다.
2. `D1` 폴더를 고릅니다.
3. 파일 이름 칸에 `d1_end_eda__T조-번호`를 입력합니다(예: `d1_end_eda__T2-07`).
4. 파일 형식이 **Excel 통합 문서(\*.xlsx)**인지 확인하고 **저장**을 누릅니다.
5. [제출 폼 링크 — 강사 입력]을 열고 Google 계정으로 로그인합니다.
6. **파일 추가**를 눌러 저장한 파일을 올리고 **제출**을 누릅니다. 마감은 **17:40 미닛카드 전**입니다.

- 다 끝내지 못했어도 그대로 제출하세요. **내일 08:30**에 강사 정답 파일(체크포인트 `d2_start.xlsx`)이 공개되어 그 파일로 2일차에 바로 합류합니다.

- **페어**: 블록 B의 Step 5–6은 두 사람이 한 화면으로 합니다. 한 사람은 마우스·키보드(드라이버), 한 사람은 지시와 확인(내비게이터). 15:25 · 16:04에 바꿉니다.
- **스티커**: 막히면 노트북 뚜껑에 빨강, 다 끝나면 초록.
- **새 일 = 새 채팅**: 한 채팅에서는 문서(파일) 하나만 다룹니다. 같은 문서로 이어 가는 프롬프트(예: P1-1 → P1-2)는 같은 채팅에, 다른 문서나 다른 일은 새 채팅에서 시작합니다.
- **파킹랏**: 강사도 모르는 현장 질문은 벽 전지나 Slido에 적습니다. 다음 날 1차 자료로 답합니다.
