## Step 5 노코드 시각화: 피벗 + 100% 누적 막대 {#step5}

**15:02–15:06 강사 시범 · 15:06–15:42 (36분)** · 코드 없이 엑셀 피벗으로 결제방식·국가·업종별 회수 지연 현황 그래프를 직접 만든다

=== "🟢 Basic"

    **준비 (15:02–15:06)**

    1. 짝과 드라이버·내비게이터를 정합니다.
    2. 강사 화면의 피벗① 시범을 함께 봅니다(4분). 이어서 아래 순서대로 직접 만듭니다.

    **① 바이어 시트를 템플릿으로 복사 → 표 만들기(`tbl_buyers`)**

    3. `d1_buyers_raw.xlsx`와 템플릿(내 이름으로 저장한 `d1_end_eda__T조-번호.xlsx`)을 **둘 다** 엽니다. 노란 띠(제한된 보기)가 뜬 파일은 **편집 사용**을 눌러야 이동/복사가 됩니다.
    4. `d1_buyers_raw.xlsx` 아래쪽의 **buyers** 시트 탭을 마우스 오른쪽 버튼으로 누르고 **이동/복사**를 고릅니다.
    5. '대상 통합 문서'에서 내 템플릿 파일을 고르고, '다음 시트의 앞에'에서 **(끝으로 이동)**을 고릅니다.
    6. 아래 **복사본 만들기**를 체크하고 **확인**을 누릅니다. 템플릿에 `buyers` 시트가 생깁니다.
    7. 템플릿의 `buyers` 시트에서 **A2** 셀을 클릭하고 ++ctrl+t++ 를 누릅니다. '표 만들기' 창의 범위가 `$A$1:$W$154`인지 보고, **머리글 포함**을 체크한 뒤 **확인**을 누릅니다.
    8. 위쪽 **테이블 디자인** 탭 → 맨 왼쪽 **표 이름** 칸을 클릭하고 `tbl_buyers`로 바꾼 뒤 ++enter++ 를 누릅니다.

    **② 새 열 4개 만들기 (X ~ AA열)**
    { #new-columns }

    표 오른쪽 끝 바로 옆(X열)에 열 이름을 쓰면 표가 저절로 넓어지고, 2행에 수식을 한 번 넣으면 아래 행 전체에 채워집니다. 아래 순서대로 만듭니다(`dpd_num`이 있어야 뒤의 두 열이 계산됩니다).

    9. **X1** 셀에 `payment_method`를 입력하고 ++enter++ 를 누릅니다.
    10. **X2** 셀에 아래 수식을 붙여 넣고 ++enter++ 를 누릅니다. 결제조건 원문을 `00_코드표`(표 이름 `tbl_codes`)에서 찾아 코드로 바꾸고, 표에 없으면 **"미분류"**라고 씁니다.

        ```text
        =XLOOKUP(UPPER(TRIM([@payment_terms_raw])),tbl_codes[raw_upper],tbl_codes[payment_method],"미분류")
        ```

        **#NAME?**이 나오면 XLOOKUP이 없는 엑셀입니다 → 바로 아래 [대안 수식](#xlookup-alt)을 씁니다.

    11. **Y1**에 `dpd_num`을 입력하고, **Y2**에 아래 수식을 넣습니다. 연체일이 숫자가 아닌 칸(글자가 섞인 칸)은 빈칸으로 둡니다.

        ```text
        =IFERROR(--[@max_dpd_days],"")
        ```

    12. **Z1**에 `aging_bucket`을 입력하고, **Z2**에 아래 수식을 넣습니다. 연체일을 구간(Current · 1-30 · 31-60 · 61-90 · 91+)으로 나누고, 빈칸은 "확인필요"로 둡니다.

        ```text
        =IF([@dpd_num]="","확인필요",IF([@dpd_num]<=0,"Current",IF([@dpd_num]<=30,"1-30",IF([@dpd_num]<=60,"31-60",IF([@dpd_num]<=90,"61-90","91+")))))
        ```

    13. **AA1**에 `is_overdue`를 입력하고, **AA2**에 아래 수식을 넣습니다. 연체면 1, 아니면 0, 연체일을 모르면 빈칸입니다.

        ```text
        =IF([@dpd_num]="","",--([@dpd_num]>0))
        ```

    14. 네 열이 맨 아래 행(154행)까지 채워졌는지 ++ctrl+down++ 으로 내려가 확인합니다.

    !!! tip "XLOOKUP이 없을 때 — 같은 일을 하는 대안 수식"
        Excel 2019·2016 이하에서는 10번 수식 대신 아래 둘 중 하나를 X2에 넣습니다. 결과는 같습니다(템플릿 `00_코드표` 오른쪽에도 같은 수식이 있습니다).
        { #xlookup-alt }

        **INDEX + MATCH** (권장)

        ```text
        =IFERROR(INDEX(tbl_codes[payment_method],MATCH(UPPER(TRIM([@payment_terms_raw])),tbl_codes[raw_upper],0)),"미분류")
        ```

        **VLOOKUP**

        ```text
        =IFERROR(VLOOKUP(UPPER(TRIM([@payment_terms_raw])),tbl_codes[[raw_upper]:[payment_method]],2,FALSE),"미분류")
        ```

        VLOOKUP의 숫자 `2`는 '`raw_upper`부터 세어 두 번째 열(`payment_method`)'이라는 뜻입니다.

    **③ '미분류' 정리 → `00_코드표`에 한 줄씩**

    15. `payment_method` 머리글의 ▼를 누르고 **모두 선택**을 해제한 뒤 **미분류**만 체크 → **확인**을 누릅니다.
    16. 남은 행의 `payment_terms_raw` 원문을 읽고, 위의 [결제방식 코드 7종](#files) 중 어느 것인지 정합니다. Step 4의 AI 표0 매핑표도 참고하되, 애매하면 짝과 상의합니다 — 여러분이 무역금융 전문가입니다.
    17. 그 행의 `payment_terms_raw` 칸을 클릭하고 ++ctrl+c++ 를 누릅니다.
    18. `00_코드표` 시트로 가서 `tbl_codes` 표 바로 아래 **첫 빈 줄의 A칸**(raw_variant — 처음에는 48행, 다음에는 49행 …)을 마우스 오른쪽 버튼으로 누르고 **붙여넣기 옵션 → 값**(123 아이콘)을 고릅니다. 표가 한 줄 늘어납니다.
    19. 같은 줄 **B칸**(raw_upper)에 `=UPPER(TRIM([@raw_variant]))`를 입력합니다(대문자로 직접 써도 됩니다).
    20. **C칸**(payment_method)의 ▼에서 코드를 고릅니다. 판단이 어려우면 임시로 **확인필요**를 고릅니다.
    21. **D칸**(설명)에 그렇게 판단한 이유를 한 줄 씁니다.
    22. `buyers` 시트로 돌아와 그 행의 `payment_method`가 '미분류'에서 코드로 바뀌었는지 봅니다. **데이터** 탭 → **다시 적용**을 누르면 남은 '미분류'만 다시 보입니다. 안 바뀌었으면 원문을 정확히 옮겼는지(오탈자) 확인합니다.
    23. '미분류' 행이 모두 사라질 때까지 16–22번을 반복합니다. 같은 표기는 한 번만 추가하면 그 표기를 쓴 행이 모두 바뀝니다(대소문자·앞뒤 공백만 다른 표기도 같은 표기로 칩니다).
    24. 판단이 애매해 '확인필요'로 둔 표기는 `03_EDA` 진단 목록 표의 빈 줄에 유형 '결제조건 애매'로 한 줄 추가하고 **왜 애매한지** 적습니다. 애매한 결제조건 자체가 위험 신호일 수 있습니다.
    25. `payment_method` 머리글의 ▼ → **"payment_method"에서 필터 해제**를 눌러 전체 행을 다시 봅니다.

    **④ 피벗① 결제방식 × 연체 구간(행 비율) + 100% 누적 가로 막대**

    26. `tbl_buyers` 안 아무 셀을 클릭하고 **삽입** 탭 → **피벗 테이블**을 누릅니다(메뉴가 펼쳐지면 **표/범위에서** — 버전에 따라 '테이블/범위에서').
    27. '표/범위'가 `tbl_buyers`인지 보고 **기존 워크시트**를 고릅니다. '위치' 칸을 클릭한 뒤 `04_피벗` 시트 탭 → **A22** 셀을 클릭하고 **확인**을 누릅니다.
    28. 오른쪽 '피벗 테이블 필드' 창에서 `payment_method`를 **행**, `aging_bucket`을 **열**, `buyer_id`를 **값**으로 끌어 놓습니다. 값에 '개수: buyer_id'가 보입니다. 행이나 열에 '확인필요'가 보여도 정상입니다.
    29. 이 상태(개수)에서 **91+ 열 맨 아래 총합계**를 `03_EDA` **C67**(91+ 바이어 수의 엑셀 숫자)에 적습니다.
    30. 값 영역의 '개수: buyer_id' ▼ → **값 필드 설정** → **값 표시 형식** 탭 → **행 합계 비율**을 고르고 **확인**을 누릅니다.
    31. 열 순서를 Current → 1-30 → 31-60 → 61-90 → 91+ 로 맞춥니다: 'Current' 머리글 칸을 마우스 오른쪽 버튼 → **이동** → **'Current'을(를) 처음으로 이동**.
    32. 피벗① 안 아무 셀을 클릭하고 **피벗 테이블 분석** 탭 → **피벗 차트** → **가로 막대형** → **100% 기준 누적 가로 막대형** → **확인**.
    33. 차트 제목을 클릭해 `결제방식별 연체 구간 구성(행 비율)`으로 바꾸고(제목이 없으면 차트 오른쪽 위 **＋** → **차트 제목** 체크), 차트를 **J22** 근처 점선 칸으로 끌어 놓습니다.

    **⑤ 피벗② 국가별 연체 바이어 비율 상위 10**
