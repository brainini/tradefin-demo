## 이 페이지에 대해 {#about}

- 이 페이지는 저장소의 `labs/day6/prompts.md`를 그대로 보여 줍니다. 같은 프롬프트를 [6일차 안내](../day6/index.md)의 역할별 작업과 [솔루션 킷](../day6/kit.md)의 파일 자리에서 씁니다. 저장소 · 릴리스는 [기초 F6](../foundations/f6.md)과 함께 봅니다.
- **모든 6일차 프롬프트는 팀이 넣은 숫자만 쓰고, 끝에 '사람 검토 체크리스트'를 붙입니다.** 한도 변경 · 선적 보류 · K-SURE 통지 · 바이어 발송은 사람이 승인합니다.
- **모델 이름 대신 '기본 모델 / 추론 모델'**: 서비스마다 모델 이름과 고르는 메뉴가 다르고 자주 바뀝니다. 결과가 이상하면 같은 프롬프트를 추론 모델로 바꿔 비교해 보세요.
- **데이터 위생**: 팀 저장소에는 가상 데이터만 올립니다. 개인 KPI · 기획서의 자사판은 [익명화 체크리스트](../setup.md#byod)를 통과한 값만 쓰고 비공개 폼으로만 냅니다.
- 6일차 프롬프트는 10/20(화) 18:00에 공개합니다. 위쪽이 비어 있으면 아직 공개 전입니다.
