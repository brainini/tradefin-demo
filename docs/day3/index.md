### 3.4 실습 개요 {#practice-overview}

> o 3일차 : 외부 금융 변수를 결합한 300일¹ 이내 대금 연체 확률 및 환율 위험 구간 예측

| 실습배경(원문) | 실습목표(원문) |
|---|---|
| o 정상 거래 속에서 아주 드물게 발생하는 부도 거래(클래스 불균형)를 일반적인 방식으로 분석할 경우 AI가 위험을 놓치는 문제 발생. 마우스 클릭 기반의 머신러닝 도구를 활용하더라도 금융 리스크의 특성에 맞는 정확한 평가 지표(ROC-AUC, Precision, Recall) 검증과 모델의 예측 결과에 대한 해석(SHAP) 인프라가 필수적임. | o 클래스 불균형 데이터를 SMOTE 기법 등으로 보정하고, 비즈니스 목적에 맞춰 임계값을 정밀 제어하여 해당 바이어가 '30일 이내에 대금을 연체할 확률'을 정확하게 도출하는 머신러닝 분류 모델 구현 역량 배양 (예측 기간 30일로 통일 및 검증 지표 고도화) |
| | o 3일차 : 과거 거래 이력 데이터를 바탕으로 미래 대금 연체 확률 및 바이어 리스크 등급 예측 |

¹ 원문의 '300일'은 오기로 보고 **30일**로 씁니다 — 같은 표의 3일차 결과물과 5-3 실습 목표가 '30일 이내'(예측 기간 30일로 통일)입니다.
실습 특징: Orange(LightGBM → xgboost · SMOTE → 학습셋 복제 오버샘플 · class weight · Prophet → 엑셀 ETS / Orange ARIMA) · 원형은 Colab · 3트랙(Basic 전원 완주).

## 함께하는 규칙 {#rules}

- **1:1 순회**: 강사가 블록마다 한 바퀴, 한 분씩 3분 체크합니다.
- **스티커**: 막히면 노트북 뚜껑에 빨강, 다 끝나면 초록.
- **Replicable은 모두 켭니다**: Data Sampler와 Gradient Boosting의 Replicable 체크가 오늘의 시드입니다.
- **숫자보다 절차**: 시험셋 연체가 몇 건뿐이라 AUC가 조마다 다릅니다. 옆 사람과 숫자가 달라도 절차가 같으면 정상입니다.
- **파킹랏**: 강사도 모르는 현장 질문은 벽 전지나 Slido에 적습니다. 다음 날 1차 자료로 답합니다.

!!! success "오늘의 습관 세 가지"
    1. **연체가 드물면 정확도 대신 FN(놓친 연체)과 비용**을 본다.
    2. **임계값은 경영 결정** — 비용 비율로 정하고 근거 한 줄을 남긴다.
    3. **등급에는 근거 3줄** — SHAP은 이유이지 원인이 아니다. 결정은 사람이 한다.
