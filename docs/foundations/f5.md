!!! abstract "한 줄"
    `streamlit run`으로 띄운 앱은 **내 PC에서만** 열립니다. 모두가 쓰려면 클라우드 서버에서 계속 돌도록 **배포**하고,
    키 같은 **비밀값은 저장소가 아니라 Secrets 칸**에 둡니다. 함께 고칠 때는 **fork → PR → 리뷰**로 합칩니다.

    교수방법 "실습: Streamlit 및 대화형 AI 프레임워크 툴을 활용한 나만의 웹 상황판 풀스택 패키징 실습"

## 1. 비유 — 거실 가게와 상가 점포 {#analogy}

- **`streamlit run app.py` = 내 집 거실에 가게를 연 것.** 주소 `localhost:8501`은 "우리 집(localhost)의 8501호 문(포트)"입니다. 집 안 사람만 들어올 수 있고, 창(프로그램)을 닫으면 가게도 닫힙니다.
- **배포 = 상가에 점포를 얻어 늘 열어 두는 것.** Streamlit Community Cloud가 GitHub 저장소의 코드를 가져가 계속 돌려 줍니다.
- **비밀값(API 키) = 금고 비밀번호.** 장부(저장소)에 적지 않고 금고(Secrets 칸)에만 둡니다.
- **fork · PR · 리뷰 = 사본 → 수정 제안서 → 결재.** 서류 사본을 떠서 고친 뒤(fork · 브랜치), 수정 제안서(PR)를 올리고, 결재(리뷰)를 받아 원본에 반영(병합)합니다.
- **풀스택 4층 = 화면 · 로직 · 데이터 · 외부 연동.** 버튼 한 번의 '요청 1건'이 화면 → API 서버 → 모델 → DB·저장소를 지나 돌아옵니다.

## 3. 용어 {#terms}

| 용어 카드 | 한 줄 정의 |
|---|---|
| 용어 5-13 **서버 프로세스 · localhost·포트 → 배포** | 요청을 기다리며 계속 실행 중인 프로그램 · 내 컴퓨터와 그 안의 문 번호 · 클라우드 서버에 올려 누구나 주소로 쓰게 하기 |
| 용어 5-14 **API 키 · 환경변수·Secrets** | 유료 AI 서비스를 쓰는 비밀 열쇠 · 비밀값을 코드·저장소 밖에 따로 두고 앱이 읽게 하는 칸 |
| 용어 5-15 **fork · PR · 리뷰** | 남의 저장소를 내 계정으로 복사한 사본 · 내 변경을 합쳐 달라는 제안 · 합치기 전에 다른 사람이 검토하기 |
| 띠 **명세 · 인수 기준(Given/When/Then)** | 만들기 전에 입력 · 출력 · 완료 조건을 "~일 때 ~하면 ~된다"로 적은 문서 |

알아 둘 것

- **Community Cloud**: 12시간 동안 아무도 접속하지 않으면 잠들고(깨우기 버튼 → 1–2분), 비공개 앱은 계정당 1개라 수업 앱은 **공개 앱 + 합성 데이터**로 만듭니다.
- **저장소에는 값 없는 견본만**: `secrets.toml.example`은 커밋하고, 진짜 `secrets.toml` · `.env`는 `.gitignore`로 막습니다. 웹 화면 업로드는 막지 못하니 직접 확인합니다.
- **명세 먼저**(P5-4): AI에게 기능을 시키기 전에 세 줄을 씁니다. <span class="chip chip--virtual">[가상 예시]</span>

    ```text
    Given 연체 15일 이상이고 등급이 C인 바이어가 있을 때
    When 대시보드에서 '독촉 초안' 버튼을 누르면
    Then 강한 톤의 영문 메일 초안이 만들어지고, 사람이 승인하기 전에는 보내지지 않는다(DRY RUN)
    ```

## 5. 익명 실패 사례 {#case}

<span class="chip chip--field">[현장 사례 · 익명]</span> **"비밀값이 저장소로"**

여러 프로젝트에서 같은 실수가 반복됐습니다. 설정 파일에 AI 서비스 키를 그대로 적어 둔 채 저장소가 그 파일을 추적하게 두거나,
`.env` 파일을 커밋한 채 원격 저장소에 올린 경우입니다. 한 번 올라간 키는 파일을 지워도 커밋 이력에 남습니다.

**교훈** — 키는 처음부터 Secrets · 환경변수에 두고, 저장소에는 값 없는 견본만 둡니다. 노출되면 지우는 것보다 **교체**가 먼저입니다.

## 6. 완료 체크리스트 {#checklist}

- [ ] `localhost:8501`이 무엇이고, 왜 창을 닫으면 앱이 꺼지는지 설명할 수 있다
- [ ] 내 앱 주소가 다른 사람의 노트북·휴대폰에서도 열린다
- [ ] API 키를 Secrets 칸에만 넣었다(저장소 · 대화창 · 채팅방에 없음)
- [ ] 기능 1개를 명세(Given/When/Then)부터 쓰고 추가했다
- [ ] 팀 저장소에 PR 1건을 열고, 다른 팀원의 PR 1건을 리뷰했다
- [ ] 독촉 메일은 초안·승인 기록까지만 만들었다 — 실제 발송 0건
