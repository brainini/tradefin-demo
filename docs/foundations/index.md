# 기초 지식 트랙 F1–F6

!!! abstract "이 트랙은 무엇인가"
    AI로 데이터를 분석하고, 나만의 작은 솔루션을 만들고, 업무를 자동화해 보려는 **비개발자**를 위한 기초입니다.
    코드를 '쓰는' 법이 아니라, **AI가 만든 결과를 실행 · 검증 · 보관 · 공유하는 법**을 다룹니다.
    하루 15–25분 설명을 듣고, 그날 실습 Step 하나에서 바로 써 봅니다. 트랙(🟢🔵🟣)과 상관없이 전원이 함께합니다.

## 각 페이지 읽는 법 {#how-to-read}

모든 모듈은 같은 순서입니다: **비유 → 그림 → 용어 → 오늘 실습 어디서 만나나 → 익명 실패 사례 → 완료 체크리스트**.

- 그림 자리의 `IMG` 키는 강사 이미지 목록의 번호입니다(`NEW`는 새로 찍을 화면). 이미지가 들어가면 출처·확인일·이용 근거가 적힌 캡션이 함께 붙습니다.
- <span class="chip chip--field">[현장 사례 · 익명]</span>은 강사가 참여한 프로젝트의 경험입니다. 회사·기관 이름은 밝히지 않습니다.
- 용어의 자세한 정의는 [용어집](../glossary.md)에 일차별로 있습니다.
