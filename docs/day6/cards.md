# 6일차 · 위기 카드

!!! info "카드 내용은 10/21(수) 09:28 공개 · 봉투는 09:30"
    위기 카드는 **종이(A5) 봉투**로 받습니다. 카드 원문 · 데이터 팩 · 팀 데이터 팩은 **09:28** 릴리스 `d6-start`와 함께 [아래 파일 표](#files)에 링크가 생기고, 봉투는 **09:30** 신호에 엽니다.
    그 전에는 이 페이지에서 카드가 어떻게 생겼는지, 어떤 순서로 읽는지만 봅니다. 카드 내용을 미리 알려 드리지 않는 것도 훈련의 일부입니다 — 실제 위기는 예고 없이 옵니다.

카드는 계획서의 **"1페이지 분량의 위기 대응 시나리오 카드"**이고, 함께 받는 데이터 팩은 **"300개 이내의 금융/채권 문장 행(Row)으로 구성된 융합 데이터"**입니다(계획서 6일차 데이터 원문). 카드를 받는 순간부터 [Step 1](index.md#step1)이 시작됩니다.

## 카드 한 장에 들어 있는 것 {#anatomy}

| 칸 | 내용 | 먼저 보는 역할 |
|---|---|---|
| 상황(T+0) | 오늘 아침 벌어진 일 — 바이어 · 국가 · 금액 · 요청 | 전원 |
| 트리거 데이터 | 데이터 팩에서 바뀌는 값 — 어느 바이어의 무엇이 얼마나(`buyer_changes` · `invoice_changes` · `scenarios`) | ① 데이터 |
| 실제 앵커 | 카드가 기대고 있는 실제 사실과 출처 | ④ 규정 · RAG |
| 핵심 질문 5 | 팀이 오늘 답해야 할 질문 | 역할마다 |
| 기대 산출 | 표 · SOP 장 · 메시지 초안 등 | ⑤ SOP · 발표 |
| 용어 상자(뒷면) | 카드에 나오는 무역금융 용어 풀이 | 전원 |

- 카드의 상황과 숫자는 <span class="chip chip--virtual">[교육용 가정]</span>입니다. '실제 앵커'만 출처가 있는 사실이고, 실존 피해 기업의 이름은 쓰지 않습니다.
- **최소 완료 기준**: 핵심 질문 5개 중 3개 + 인젝트 2개 대응. [심사 기준](judging.md#criteria)의 1–4점 설명은 카드와 상관없이 같습니다(카드 난이도 보정 없음).
- 카드가 묻는 무역금융 판단(어느 위험인지, 통지할지, 선적을 멈출지)은 팀이 근거를 달아 내립니다. AI는 초안과 근거 찾기를 돕고, 결정은 사람이 합니다.

## 데이터 팩 읽는 법 {#pack}

**팀 데이터 팩** `team_0{조}.xlsx` — 우리 카드에 필요한 조각만 모은 파일입니다. 먼저 이 파일로 시작합니다.

| 시트 | 무엇 | 쓰는 역할 |
|---|---|---|
| `README` | 우리 팀 · 카드 · 기준일(AsOf = T+0) · 시트 안내 · 체크포인트 · 만들 파일 이름 | 전원 |
| `card` | 카드 요약과 핵심 질문 5 | 전원 |
| `buyer_changes` | 바이어 단위 변경. 빈칸 = 그대로, 반영한 줄은 `applied`에 ✔ — ✔ 개수 = 이 시트의 행 수 | ① |
| `invoice_changes` | 인보이스 단위 변경(경보 시트에 붙이기 전에 바꾼다) | ① |
| `scenarios` | 카드 시나리오 값(PD 배수 · LGD · 원/달러 · 금리) → 4일차 `11_Scenario`의 U1 줄 | ③ |
| `buyers` | 대상 바이어의 지금 값(등급 · pd_30d · 한도 등) | ① · ② |
| `open_inv` | 대상 바이어의 미결 인보이스 | ① · ③ |
| `deadlines` | **카드 반영 전** 기한(D+30 · 사고발생통지 기한) — 카드 변경을 넣어 다시 계산하는 것이 ③의 일 | ③ |
| `limit_realloc` | 한도 재배정 표 — 왼쪽은 지금 값, 오른쪽 빈칸을 팀이 채움. 감액 30% 이상 = 사람 승인(빨간색) | ③ |

**전체 데이터 팩** `d6_crisis_pack.xlsx` — 다섯 카드 전체가 한 파일에 있습니다(`cards` · `injects` · `buyer_changes` · `invoice_changes` · `scenarios` · `limit_realloc` · `budget` 등). 필터로 우리 카드 번호만 골라 씁니다. `budget` 시트(가상 기업의 연간 채권 관리 · 대외 자문 예산)는 [Step 5](index.md#step5) ROI의 비용 칸에 씁니다. `injects` 시트에는 시각과 쓰는 파일만 있고, 내용은 투입 시각에 카드로 공개합니다.

| 인젝트 | 시각 | 받는 팀 | 무엇을 남기나 |
|---|---|---|---|
| **I-1** | **11:30** | 전 팀 공통 | 카드의 지시대로 계산한 결과 1줄 → SOP의 해당 장 |
