# 용어집

그날 처음 나오는 용어를 **일차별로** 모았습니다. 슬라이드의 "용어 1-12"는 1일차 12번 카드라는 뜻입니다.

| 표시 | 뜻 |
|---|---|
| **카드** | 슬라이드 한 장에 용어 하나(정의 · 비유 · 그림 · 무역금융 예 · 흔한 오해 · 쓰는 곳) |
| **카드 2-up** | 대비해야 이해되는 두 용어를 한 장에 |
| **띠** | 지나가며 한 번 나오는 용어 — 슬라이드 아래 한 줄과 이 용어집에만 |

정의는 이 과정에서 쓰는 뜻을 한 줄로 줄인 것입니다. 정의의 출처와 무역금융 예는 슬라이드 카드에 있습니다.

!!! tip "하루 10분 복습 — AI 학습 모드로"
    AI 서비스의 학습·가이드 모드(서비스마다 이름이 다르고 자주 바뀝니다)를 열고 아래를 붙여 넣으면, 그날 용어로 퀴즈를 냅니다.

    ```text
    아래 용어 10개로 나에게 퀴즈를 내 줘. 한 번에 한 문제씩, 정답을 바로 알려 주지 말고 힌트부터 줘.
    무역금융 실무자가 헷갈리기 쉬운 부분을 골라 묻고, 끝나면 내가 틀린 용어만 다시 정리해 줘.
    [용어] {용어집에서 오늘 용어 10개를 복사해 붙여 넣기}
    ```
