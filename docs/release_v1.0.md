## 이 릴리스에 든 것
- `README.md` — 5항목 + 재현 절차
- `data/` — 가상 바이어 12곳 입력(`input/v2_buyers.csv`)
- `app/` — V2 카드 파이프라인(`pipeline/v2_run.py`)
- `out/` — 파이프라인 결과 4개(`v2/`)
- `docs/` — 결정 기록 3행 · 킷 점검표 · 이 릴리스 노트
- `sop/` · `roi/` — 템플릿 상태(내용 파일 없음)
- `tools/` — 그날 파일 받기(`get_day_files.py`)
- `.claude/` · `.github/` — 권한 설정 · 이슈/PR 양식

## 다시 돌리는 법
1. 새 폴더에서 `uv sync`
2. 비공개 입력 3종(`cards/` · `local/` · `data/input/v2_demo_open_inv.csv`)을 저장소 관리자에게 받아 같은 자리에 둔다
3. `uv run python app/pipeline/v2_run.py` → `out/v2/` 4개 파일과 검산 3줄(한도 합계 880,000 → 730,000 USD · EL 합계 8,364 → 38,757 USD)

- 한도 변경 — 감액 30% 이상 2건(SB07 100,000 → 0 · SB01 90,000 → 60,000)은 `out/v2/limits_diff.csv`에 '승인 필요'로 표시되고, 결정은 `docs/decision_log.md`에 사람이 적는다
- 선적 보류(SB07 앞 선적) — `docs/decision_log.md`의 결정 3행 중 하나, 결정자 칸은 비어 있음

## 알려진 한계 · 확인 필요
- 바이어 12곳 · 등급별 한도 상한 · LGD 0.6은 시연용 단순 가정
