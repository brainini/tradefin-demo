| 실습배경(원문) | 실습목표(원문) |
|---|---|
| o 새로운 해외 바이어와의 계약이나 여신 한도를 검토할 때마다 회사 내부의 복잡한 여신 관리 지침이나 무역보험 약관 PDF를 실무자가 일일이 찾아 가며 대조해야 하는 수작업의 비효율성 존재 | o 사내 여신 지침이나 약관 문서를 AI가 실시간으로 찾아 올바른 규정만 답변하도록 만드는 '지식 검색(RAG) 엔진' 설계 원리 학습 |
| o 바이어 리스크 모니터링, 안전 한도 계산, 다국어 독촉 메일 발송 등 각각의 채권 관리 단계가 단절되어 있어 실무자가 매번 데이터를 직접 옮겨 다니며 처리하는 번거로움이 발생함 | o 거래 내역을 분석하고 사내 규정을 매칭하여 위험 바이어에게 경고를 띄우는 금융 자율형 AI 에이전트 워크플로우 설계 능력 배양 |
| o 초보자 개인이 따로 쓰던 AI 기술을 하나로 묶어, 바이어 위험 진단부터 최종 독촉 메일 발송까지 알아서 연쇄 처리하는 AI 에이전트와 이를 한눈에 관리할 모니터링 대시보드 구축 역량이 시급함 | o 바이어별 부도 위험도와 매출채권 잔액 현황 정보를 직관적으로 한눈에 관리할 수 있는 통합 제어 웹 화면(대시보드) 구현 및 연동 기법 체득 |
| | o 사용자가 거래 내역만 넣으면 위험 예측부터 RAG 규정 검토, 영문 독촉 메일 발송까지 원스톱으로 처리해 주는 '자사 맞춤형 통합 금융 AI 솔루션' 시제품 최종 완성 |
| | o 5일차 : 등급별 영문 독촉 메일 발송망 및 사내 여신 지침 자동 검색(RAG) 기능이 포함된 대시보드 화면 설계 |
