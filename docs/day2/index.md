## 함께하는 규칙 {#rules}

- **1:1 순회**: 강사가 블록마다 한 바퀴, 한 분씩 3분 체크합니다.
- **스티커**: 막히면 노트북 뚜껑에 빨강, 다 끝나면 초록.
- **새 일 = 새 채팅**: 진단(P1-3) · 수식(P2-1) · 점수화(P2-2 → P2-3)는 채팅을 나눕니다. 점수화의 배치 1 · 2와 P2-3은 같은 채팅에서 이어 갑니다.
- **정답은 화면으로**: 블록 A 14:45 · 블록 B 16:45에 강사 화면으로만 공개합니다. 골든셋 20건만 15:35에 파일로 엽니다.
- **파킹랏**: 강사도 모르는 현장 질문은 벽 전지나 Slido에 적습니다. 다음 날 1차 자료로 답합니다.

!!! success "오늘의 습관 세 가지"
    1. **변환했으면 검산한다** — 행 수 · 건수 · 손계산.
    2. **기준일 이전 값만 붙인다** — 환율은 기준일 또는 직전 영업일(as-of), 뉴스는 기준일 전 30일.
    3. **점수보다 기준이 먼저** — 앵커 · 근거(evidence) · 골든셋으로 검증해서 쓴다.
