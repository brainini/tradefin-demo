## Step 1 진단 {#step1}

**13:00–13:10 (10분)** · 고치기 전에 오늘 표의 오염을 유형별 목록으로 만든다 — 1일차의 '수정 금지 진단' 습관을 그대로 쓴다

=== "🟢 Basic"

    **① `d2_start.xlsx` 열기 · 시트 둘러보기**

    1. `D2` 폴더의 `d2_start.xlsx`를 더블클릭하고, 노란 띠가 뜨면 **편집 사용**을 누릅니다.
    2. 아래쪽 시트 탭 8개를 봅니다: `buyers`(오늘 정제할 표) · `buyer_features_raw` · `fx_at_ref` · `invoices_raw` · `dirty_list` · `map_ccy` · `map_country` · `dictionary`.
    3. `dirty_list` 시트를 엽니다. 강사가 제안한 오염 8유형(유형 · 컬럼 · 예시 · 처리 방법)이 있습니다. 오늘은 이 목록을 **내 눈으로 확인**하고, 맨 오른쪽 **비고(G열)**에 '내 진단'을 적습니다.

    **② 필터로 직접 보기 — 원본은 고치지 않는다**

    4. `buyers` 시트에서 **A1** 셀을 클릭하고 **데이터** → **필터**를 누릅니다. 열 이름마다 ▼가 생깁니다.
    5. **`currency`** ▼를 누르면 값 목록이 보입니다. 같은 통화가 몇 가지로 적혀 있는지 세어 `dirty_list` 1행 G열에 적습니다(예: `표기 ○가지 — usd · US$ …`). 목록만 보고 **확인**은 누르지 않습니다(**취소**).
    6. **`ar_balance`** 열을 내려 보며 **왼쪽으로 붙은 값**이나 칸 왼쪽 위 **초록 삼각형**을 찾습니다 — 숫자처럼 보이는 글자입니다. ▼ 목록 맨 아래쪽에도 글자 값이 따로 모여 있습니다. 몇 칸인지 2행 G열에 적습니다.
    7. 재무 열(`current_assets` ~ `operating_income`) 하나의 ▼를 눌러 목록 맨 아래 **(필드 값 없음)**만 체크하면 빈칸인 바이어가 보입니다. 몇 행인지 5행 G열에 적고, ▼ → **"…"에서 필터 해제**로 되돌립니다.
    8. **`equity`** ▼ → **숫자 필터** → **보다 작음** → `0` → 음수 자본(자본잠식) 바이어 수를 6행에, **`oecd_crc`** ▼에서 `-` 표기 수를 7행에 적습니다.
    9. **데이터** → **지우기**로 필터를 모두 풉니다. `buyers` 시트의 값은 하나도 바꾸지 않았는지 봅니다.

    **③ AI 진단(P1-3)과 대조**

    10. AI 화면에서 **새 채팅**을 열고 입력창의 **＋**(또는 클립) → **파일 업로드**로 `d2_start.xlsx`를 올립니다. 엑셀 파일이 안 올라가면 `buyers` 시트만 CSV로 저장해 올립니다(**파일** → **다른 이름으로 저장** → **CSV UTF-8(쉼표로 분리)**).
    11. **P1-3**을 붙여 넣고, `[맥락]` 줄의 `기준일 2026-09-30`을 **`2026-08-31`**로 바꿉니다. 맨 아래 `[이번 입력]`은 파일 `d2_start.xlsx(시트 buyers)` · 사전 `같은 파일의 dictionary 시트`로 바꿔 보냅니다.

        ??? example "P1-3 데이터 진단(수정 금지) — 펼쳐서 복사"
            [프롬프트 라이브러리에서 P1-3 보기(1일차)](../prompts/day1.md#p1-3)

            --8<-- "labs/day1/prompts.md:p1-3"

    12. AI가 '정리한 표'나 새 파일을 내놓으면 받지 않고 `고친 결과는 버리고, 원본 그대로 센 숫자로 다시 진단만 하라.`를 보냅니다.
    13. AI의 **오염 목록** 표를 첫 데이터 줄부터 끌어 선택해 복사하고, `dirty_list` 시트 **A12** 칸에 붙입니다(위의 8유형 표 아래).
    14. 위 8유형과 AI 목록을 대조해 G열에 표시합니다 — `✔ 둘 다` · `AI만` · `나만`. 서로 다르면 원본에서 한 번 더 확인합니다. 순회 때 강사가 묻습니다: **"AI 진단과 내 진단이 다른 곳은 어디입니까?"**
    15. ++ctrl+s++ 로 저장합니다(파일 이름은 아직 그대로).

=== "🔵 Standard"

    **자사 엑셀 익명화본도 같은 방식으로 진단** · Basic ①–②를 끝낸 뒤 합니다.

    1. 내 회사 바이어 엑셀이 [익명화 체크리스트](../setup.md#byod)를 **모두** 통과했는지, `byod_anonymize_template.xlsx`의 점검표로 다시 확인합니다.
    2. 익명화본은 **원본도 익명화본도 AI에 올리지 않습니다** — Basic ②처럼 필터로 직접 진단합니다. 회사가 허용한 AI(학습 꺼짐)가 있으면 그때만 P1-3을 씁니다.
    3. 진단 결과를 내 파일의 새 시트 `dirty_list`에 같은 열(유형 · 컬럼 · 예시 · 처리 방법)로 적습니다. 예시 칸에는 실제 값 대신 **유형 설명**만 씁니다(예: `통화 기호가 붙은 숫자`).
    4. 이 파일은 내 PC에만 둡니다 — 저장소 · 제출 폼에 올리지 않습니다.

=== "🟣 Challenge"

    **Colab 노트북 열기** · `d2_challenge.ipynb`

    1. [colab.research.google.com](https://colab.research.google.com)에 개인 Google 계정으로 들어가 **파일** → **노트북 업로드** → `d2_challenge.ipynb`를 엽니다.

    3. 왼쪽 폴더 아이콘 → 업로드로 `d2_start.xlsx` · `fx_krw_daily.csv`를 올리고, 로드 칸을 실행합니다. 행 수(150)와 열 수를 Basic 결과와 맞춰 봅니다.

## Step 2 규칙 문서 {#step2}

**13:10–13:25 (15분)** · 셀을 고치기 전에 규칙을 글로 남긴다 — 계획서 '누락 데이터 자동 정정 체계'의 첫 판이고, 8교시 첫 커밋의 주 파일이다

=== "🟢 Basic"

    **① `정제규칙.md` 틀 만들기**

    1. 아래 상자를 펼쳐 오른쪽 위 복사 버튼 :material-content-copy: 으로 틀을 복사합니다.

        ??? example "정제규칙.md 틀 — 펼쳐서 복사"
            ```text
            # 정제규칙 — 2일차

            ## 0. 메타
            - 작성: T{조}-{번호}
            - 기준일(AsOf): 2026-08-31
            - 입력 파일: d2_start.xlsx (시트 buyers)

            ## 1. 통화
            규칙:
            왜:

            ## 2. 숫자 변환

            왜:

            규칙:
            왜:

            ## 4. 단위 의심
            규칙:
            왜:

            ## 5. 자본잠식
            규칙:
            왜:

            ## 6. 국가위험
            규칙:
            왜:

            ## 7. 환율 · 시차
            규칙:
            왜:

            ## 8. 뉴스 창
            규칙:
            왜:

            ## 9. 변경 기록
            | 날짜 | 무엇 | 왜 |
            |---|---|---|
            ```

    2. 메모장을 열고 ++ctrl+v++ 로 붙여 넣습니다.
    3. **파일** → **다른 이름으로 저장** → `D2` 폴더 → 파일 이름 `정제규칙.md` → **파일 형식: 모든 파일(\*.\*)** → **인코딩: UTF-8** → **저장**. (Mac: 텍스트 편집기 → **포맷** → **일반 텍스트로 만들기** 후 저장)
        - 메모장이 불편하면 `d2_start.xlsx`에 새 시트 `rules`를 만들어 써 두고, 8교시에 `.md`로 옮겨도 됩니다.

    **② 규칙마다 '규칙:' 한 줄 + '왜:' 한 줄**

    4. [이론 2.3.1](theory.md#m231)의 오염 여섯 유형과 Step 1의 `dirty_list`를 보며 칸을 채웁니다. 최소 기준은 **1 통화 · 2 숫자 변환 · 3 결측 · 4 단위 의심**과 각각의 '왜', 그리고 0번의 **기준일**입니다.
    5. 무엇을 써야 할지 막히면 이렇게 생각합니다 — '규칙'은 **다른 사람이 읽고 똑같이 고칠 수 있는 문장**, '왜'는 **그렇게 안 하면 무엇이 틀어지는가**입니다.

        | 칸 | 쓰는 방향(예시는 형식만) |
        |---|---|
        | 1 통화 | 원천 표기 → 4종 코드(USD · EUR · JPY · CNY)로, 매핑표 이름 |
        | 2 숫자 변환 | 무엇을 지우고 숫자로 바꾸나, 수식으로 안 되는 표기는 어떻게 하나 |
        | 3 결측 | 어떤 열을 무엇으로 채우나 · 채우지 않는 열은 무엇인가 · 비어 있었다는 표시를 남기나 |
        | 4 단위 의심 | 어떤 조건이면 '단위 의심'인가(오늘 기준: USD 잔액 > 신용한도 × 10, [교육용 가정]) · 걸리면 무엇을 확인하나 |
        | 5 자본잠식 | 자기자본 ≤ 0이면 표시는? 부채비율은? |
        | 6 국가위험 | `oecd_crc`의 `-`는 어떻게? |
        | 7 환율 · 시차 | 어느 날의 환율을 붙이나(as-of) · 엔화 단위 |
        | 8 뉴스 창 | 기준일 전 며칠의 뉴스를 쓰나 — 기준일 **포함**, 30일 전 날짜는 **제외** |

    6. 저장합니다(++ctrl+s++).

    **③ `map_ccy` 채우기 — 매핑표는 규칙 1의 실물**

    7. `map_ccy` 시트를 엽니다. 머리글 `raw` · `clean`만 있습니다.

## Step 4 검산 · 특성 · 결측 대체 {#step4}

**14:15–14:45 (30분) + 정답 공개 14:45** · 변환을 검산하고, 기본 특성을 만들고, 재무비율만 규칙대로 채운다

=== "🟢 Basic"

    **① 검산표 — 변환했으면 검산한다**

    1. `d2_step1.xlsx`에 새 시트 `check`를 만들고 아래 표를 입력합니다(A열 점검 · B열 수식 · C열 기대).

        | 점검 | B열 수식 | 기대 |
        |---|---|---|
        | 행 수 | `=ROWS(tbl[buyer_id])` | 150 |
        | 통화 4종 건수 합 | `=COUNTIF(tbl[ccy_clean],"USD")+COUNTIF(tbl[ccy_clean],"EUR")+COUNTIF(tbl[ccy_clean],"JPY")+COUNTIF(tbl[ccy_clean],"CNY")` | 150 |
        | '확인필요' 수 | `=COUNTIF(tbl[ccy_clean],"확인필요")` | 0 |
        | 숫자로 안 바뀐 잔액 | `=COUNTBLANK(tbl[amt_num])` | 0 |

    2. **엔화 바이어 1곳 손계산**: `buyers`에서 `ccy_clean` ▼ → **JPY**만 → 한 행을 골라 `amt_num × fx_jpy ÷ fx_usd`를 계산기로 계산해 `check` 시트 아래에 적고, 그 행의 `ar_balance_usd`와 같은지 봅니다. 100배 차이면 `fx_jpy`의 `/100`이 빠진 것입니다.
    3. **단위 의심**: `buyers` 표의 다음 빈 열에 `unit_flag`를 만들고 아래 수식을 넣습니다(기준 10배는 [교육용 가정]).

        ```text
        =IF(AND(ISNUMBER([@ar_balance_usd]),[@ar_balance_usd]>10*[@credit_limit_usd]),"단위 의심","")
        ```

    4. `unit_flag` ▼ → **단위 의심**만 → 걸린 행의 **원천을 확인**합니다: 같은 행의 에이징 5칸(`ar_current_num` ~ `ar_91p_num`) 합계가 잔액과 같은 자릿수인가? 다르면 잔액이 다른 단위로 입력된 것입니다.
    5. 원천 확인 결과대로 그 행의 `amt_num` 칸에 고친 값을 수식으로 넣습니다(예: 에이징 5칸 합계 `=[@ar_current_num]+[@ar_1_30_num]+[@ar_31_60_num]+[@ar_61_90_num]+[@ar_91p_num]`). 원본 `ar_balance` 칸은 그대로 둡니다.
    6. `dirty_list` 4행 **처리 결과(F열)**에 **무엇(어느 바이어 · 어느 열) · 왜(무엇과 비교해 판단) · 어떻게 고침**을 한 줄로 적습니다. 이 기록이 오늘의 검산 근거입니다.

    **② 특성 수식 — 표 오른쪽에 한 열씩**

    7. `buyers` 표의 다음 빈 열마다 1행에 열 이름, 2행에 수식을 넣습니다. 빈칸 · 0 나누기는 빈칸("")이 되게 짰습니다 — 0으로 채우지 않습니다.

        | 열 이름 | 수식 | 뜻 |
        |---|---|---|
        | `pct_ar_31p` | `=IF(N([@amt_num])>0,([@ar_31_60_num]+[@ar_61_90_num]+[@ar_91p_num])/[@amt_num],"")` | 잔액 중 31일 이상 연체 비중(잔액 0이면 빈칸이 정상) |
        | `late_ratio` | `=IF(N([@invoices_12m])>0,[@late_invoices_12m]/[@invoices_12m],"")` | 12개월 연체 인보이스 비율 |
        | `dpd_trend` | `=IF(AND(ISNUMBER([@avg_dpd_last3m]),ISNUMBER([@avg_dpd_prev3m])),[@avg_dpd_last3m]-[@avg_dpd_prev3m],"")` | 최근 3개월 − 직전 3개월 평균 연체일(+면 악화) |
        | `current_ratio` | `=IF(AND(ISNUMBER([@current_assets]),N([@current_liabilities])>0),[@current_assets]/[@current_liabilities],"")` | 유동비율 |
        | `neg_equity` | `=IF(ISNUMBER([@equity]),--([@equity]<=0),"")` | 자본잠식 표시(1 = 자기자본 ≤ 0) |
        | `debt_to_equity` | `=IF(AND(ISNUMBER([@total_liabilities]),N([@equity])>0),[@total_liabilities]/[@equity],"")` | 부채비율 — 자기자본 ≤ 0이면 빈칸 |
        | `dso_buyer` | `=IF(AND(ISNUMBER([@accounts_receivable]),N([@revenue])>0),[@accounts_receivable]/[@revenue]*365,"")` | 바이어 DSO |
        | `op_margin` | `=IF(AND(ISNUMBER([@operating_income]),N([@revenue])>0),[@operating_income]/[@revenue],"")` | 영업이익률(소수) |
        | `fin_missing` | `=--(COUNT([@current_assets],[@current_liabilities],[@total_liabilities],[@equity],[@revenue])<5)` | 재무 원시 항목이 하나라도 비면 1 |

        - `ar_balance_usd`(Step 3)까지 합쳐 **기본 특성 9종**(+ `neg_equity` 표시)입니다. 수식 오류가 나면 오류 칸의 값과 수식을 **P2-1**에 붙여 묻습니다.
    8. `debt_to_equity`에 음수가 없는지(▼ 목록 맨 위), `neg_equity` = 1인 행이 있는지 봅니다. `fin_missing` = 1인 행 수를 `check` 시트에 `=SUM(tbl[fin_missing])`로 적습니다.

    **③ `features` 시트 — 모델이 읽을 표**

    9. 새 시트 `features`를 만듭니다.
    10. `buyers` 시트에서 **A열 머리 글자**(buyer_id)를 클릭하고, ++ctrl++ 를 누른 채 특성 10열(`ar_balance_usd` · `pct_ar_31p` · `late_ratio` · `dpd_trend` · `current_ratio` · `neg_equity` · `debt_to_equity` · `dso_buyer` · `op_margin` · `fin_missing`)의 **열 머리 글자**를 차례로 클릭 → ++ctrl+c++.
    11. `features` 시트 **A1** → 마우스 오른쪽 → **붙여넣기 옵션** → **값(V)**. 수식 없이 값만 들어갑니다.
    12. 다시 `buyers`의 **`late_30d`(AB열) 머리 글자** → ++ctrl+c++ → `features` 시트의 **첫 빈 열 1행** → **값(V)** 붙여넣기. `late_30d`가 **맨 끝 열**이어야 합니다.
    13. `features` 시트 **A2** 클릭 → ++ctrl+t++ → **머리글 포함** → **확인** → 표 이름 `feat`. ++ctrl+s++ 로 저장합니다(Orange는 저장된 파일만 읽습니다).
    14. `check` 시트에 재무비율 4종의 중앙값을 구해 둡니다 — `=MEDIAN(feat[current_ratio])` · `=MEDIAN(feat[debt_to_equity])` · `=MEDIAN(feat[dso_buyer])` · `=MEDIAN(feat[op_margin])`. 빈칸은 MEDIAN이 알아서 뺍니다.

    **④ Orange — 재무비율 4종만 중앙값으로 채우기**

    15. Orange를 실행하고 왼쪽 **Data** 묶음에서 **File**을 캔버스에 놓습니다. 더블클릭 → 폴더 아이콘 → `d2_step1.xlsx` → 위쪽 **Sheet** ▼ → `features`.
    16. 아래 열 표에서 `buyer_id`의 **Role**을 **meta**로, `late_30d`의 Role을 **target**으로 바꾸고 **Apply**.
    17. File 위젯 오른쪽 가장자리를 끌어 **Column Statistics**에 잇습니다. **Missing** 열에서 결측이 많은 열을 봅니다.
    18. File에서 다시 끌어 **Impute**에 잇고 더블클릭합니다.
        - **Default method**: **Don't impute**(대체 안 함)
        - 왼쪽 목록에서 `current_ratio`를 고르고 오른쪽 **Fixed values**를 선택 → 값 칸에 `check` 시트의 중앙값을 입력합니다. `debt_to_equity` · `dso_buyer` · `op_margin`도 같은 방법으로.
        - 나머지 열(`pct_ar_31p` · `dpd_trend` 등)은 채우지 않습니다 — 정의되지 않는 값이고, `fin_missing`이 '비어 있었다'는 사실을 대신 남깁니다.
    19. Impute 오른쪽에 **Data Table**을 이어 채워진 값을 봅니다.
    20. (비교) Impute를 하나 더 놓고 **Default method**를 **Model-based imputer**로 둡니다. 이 방식의 기본 모델은 **Simple Tree**(나무)이지 1-NN이 아닙니다 — 가장 닮은 바이어 값(**1-NN**)으로 채우려면 왼쪽 **Model** 묶음에서 **kNN** 위젯을 캔버스에 놓고 **Number of neighbors**를 `1`로 정한 뒤, kNN의 **Learner** 출력을 이 Impute의 **Learner** 입력에 잇습니다(강사가 준 `d2_orange_preprocess.ows`에는 이미 이어 두었습니다). Data Table로 같은 바이어의 값을 비교합니다 — 오늘 저장하는 쪽은 중앙값입니다.
    21. (보기만) Impute → **Continuize**(범주 → 0/1 열) → Data Table, Impute → **Preprocess** → **Normalize Features** → **Normalize to interval [0, 1]** → Data Table. 정규화한 값은 **저장하지 않습니다** — 3일차 모델 평가 안에서 학습 데이터 기준으로만 계산합니다.
    22. **File** → **Save As** → `D2` 폴더에 `d2_orange_preprocess.ows`로 워크플로를 저장합니다. 막혔으면 강사가 준 같은 이름의 `.ows`를 열어(**File** → **Open**) 비교합니다.

        2. 내 `check` 시트와 다른 칸은 **원인 한 줄**을 `check` 시트 D열에 적습니다 — 대개 매핑표 누락 · `/100` · 기준일 · 수식 범위 중 하나입니다.

=== "🔵 Standard"

    **17종 전체 + 중앙값 vs 1-NN 분포 비교** · Basic ①–②를 끝낸 뒤 합니다.

    1. 특성을 더 만듭니다(같은 방식, 표 오른쪽 열):

        | 열 이름 | 수식 |
        |---|---|
        | `pct_current` | `=IF(N([@amt_num])>0,[@ar_current_num]/[@amt_num],"")` |
        | `pct_91plus` | `=IF(N([@amt_num])>0,[@ar_91p_num]/[@amt_num],"")` |
        | `max_dpd` | 원천 `max_dpd` 열 그대로(숫자 확인) |
        | `avg_days_late` | `=IF(ISNUMBER([@avg_days_late_12m]),[@avg_days_late_12m],"")` |
        | `dispute_ratio` | `=IF(N([@invoices_12m])>0,[@dispute_cnt_12m]/[@invoices_12m],"")` |
        | `country_risk` | `=IF([@oecd_crc]="-",0,--[@oecd_crc])` |
        | `crc_unclassified` | `=--([@oecd_crc]="-")` |
        | `fx_chg_30d` | `fx_param`에 통화별 `=XLOOKUP(AsOf,…,-1)/XLOOKUP(AsOf-30,…,-1)-1`을 만든 뒤 SWITCH로 조회 |
        | `fx_chg_30d_lag30` | 위 식의 날짜를 30일씩 당김(AsOf−30 대비 AsOf−60) — '시차 정렬' 연습 |

    2. Orange에서 Basic ④의 두 Impute(중앙값 · 1-NN)에 각각 **Distributions**를 잇고, `current_ratio` 분포를 나란히 봅니다.
    3. `oecd_crc`(또는 `country_risk`)별로 결측이 어디에 몰렸는지 Column Statistics로 보고, **"결측이 신흥국에 몰리면 중앙값 대체가 무엇을 왜곡하나"**를 2줄로 `check` 시트에 씁니다.

=== "🟣 Challenge"

    **결측 대체 비교 · 파이프라인 안 스케일링 · 누수 점검**

    1. 결측 대체 비교 칸: `SimpleImputer(strategy="median")`와 `KNNImputer(n_neighbors=5)`의 결과 분포를 겹쳐 그립니다. 같은 기준일 150개사 안에서만 fit합니다.
    2. 스케일링 칸: `Pipeline([("imp", …), ("sc", MinMaxScaler()), ("clf", …)])` — 분할 **전에** 전체 데이터로 fit하지 않는 이유를 주석 한 줄로 씁니다.
    3. **누수 점검**: 만든 특성과 `late_30d`의 상관을 계산해 **0.9 이상**인 열이 있으면 표시하고 강사에게 알립니다(라벨 기간 정보가 섞였다는 신호).
    4. 시차 특성 칸: `fx_chg_30d`와 `fx_chg_30d_lag30`을 `shift`로 만들고, 기준일 뒤 날짜가 하나도 쓰이지 않았는지 `assert`로 확인합니다.

## 흔한 오류와 해결 {#troubleshooting}

| # | 증상 | 원인 | 해결 |
|---|---|---|---|
| 1 | 환율 셀이 **#N/A** | 기준일이 휴일(주말 · 미국 공휴일)이라 같은 날짜가 없다 | XLOOKUP 다섯째 인수 `-1`(직전 값) — 이것이 as-of 정렬입니다 |
| 2 | 엔화 바이어 금액이 다른 바이어보다 100배 크다 | `jpy100_krw`는 **100엔당** 원 | `fx_jpy` 수식 끝에 `/100` |
| 3 | 수식에 **#NAME?** | XLOOKUP · SWITCH가 없는 엑셀(2019 · 2016 이하), 또는 이름(`AsOf` · `fx_usd`) 정의가 안 됐다 | 엑셀 웹 · 구글 시트로 바꾸기([FAQ](../faq.md#q-xlookup)) · **수식** → **이름 관리자**에서 이름 5개가 있는지 확인 |
| 4 | `[@열이름]`을 어떻게 입력하는지 모르겠다 | 표 안에서 수식을 쓰면 엑셀이 만들어 준다 | `=`를 입력한 뒤 같은 행의 칸을 마우스로 클릭하면 `[@열이름]`이 자동으로 들어갑니다 |
| 5 | 2행에만 수식이 들어가고 아래가 비었다 | 표 밖에 수식을 넣었다 | 먼저 1행에 열 이름을 넣어 표를 넓힌 뒤 2행에 수식. 또는 수식 칸 옆 ⚡ → **이 수식으로 이 열의 모든 셀 덮어쓰기** |
| 6 | `fx` 표의 `date`가 왼쪽 정렬(글자)이라 XLOOKUP이 안 맞는다 | 가져오기 때 날짜 형식으로 안 바뀌었다 | `date` 열 선택 → **데이터** → **텍스트 나누기** → **마침**. 또는 가져오기 창에서 **데이터 변환** → `date` 열 형식 **날짜** |
| 7 | `ccy_clean`에 '확인필요'가 남는다 | 매핑표에 없는 표기(앞뒤 공백 · 기호 · 대소문자 변형) | 그 표기를 `map_ccy` 표 **바로 아래 줄**에 원문 그대로 더합니다(한 줄 띄우면 표 밖) |
| 8 | 중복 제거에서 많은 행이 지워졌다 | 일부 열만 체크했다 | ++ctrl+z++ 로 되돌리고 **모두 선택** 그대로 다시. 오늘 시트는 0건이 정상 |
| 9 | 붙여넣기 때 '여러 선택 영역에 사용할 수 없습니다' | 열 머리 글자가 아니라 칸 범위를 섞어 골랐다 | ++ctrl++ 를 누른 채 **열 머리 글자(A · AC …)만** 클릭해 다시 복사 |
| 10 | `dpd_trend`가 0으로 가득하다 | 빈칸끼리 뺀 값(0)이 들어갔다 | 위 표의 ISNUMBER 수식으로 바꿉니다 — 빈칸은 빈칸으로 둡니다 |
| 11 | Orange File 위젯에 `features` 시트가 안 보인다 · 값이 옛날 그대로 | 엑셀에서 저장하지 않았다 | 엑셀 ++ctrl+s++ → Orange File 위젯의 **Reload**(새로 고침) |
| 12 | Orange가 `buyer_id`를 특성으로 쓴다 | Role이 feature | File 위젯 열 표에서 `buyer_id` Role = **meta** → **Apply** |
| 13 | Impute에 중앙값 메뉴가 없다 | Orange Impute에는 중앙값 옵션이 없다 | 시트 `=MEDIAN()`으로 구해 **Fixed values**에 입력 |
| 14 | AI가 진단하지 않고 '정리한 파일'을 만들었다 | 진단과 수정을 같이 시켰다 | 받지 않습니다. `고친 결과는 버리고, 원본 그대로 센 숫자로 다시 진단만 하라.` |
| 15 | P2-1 수식이 테스트 표와 다른 값을 낸다 | 예시를 원문과 다르게 옮겼거나, 지역 설정(쉼표 · 소수점)이 다르다 | 예시를 셀에서 그대로 복사해 다시 묻고, 틀린 행을 `이 행은 기대 출력과 다르다: …`로 알려 줍니다 |
