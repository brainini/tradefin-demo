# FAQ · 트러블슈팅

막히면 먼저 노트북 뚜껑에 **빨강 스티커**를 붙이고, 아래에서 증상을 찾아보세요. 5분 안에 안 풀리면 손을 들어 주세요.
각 실습 페이지 아래에도 그 실습에서 자주 나오는 오류 표가 있습니다(1일차 [실습 A — Step 1–4](day1/lab-a.md#troubleshooting) · [실습 B — Step 5–8](day1/lab-b.md#troubleshooting)).

## 계정 · 접속

### Claude 가입 때 문자 인증이 안 돼요 {#q-claude-sms}

Claude는 휴대폰 **문자(SMS) 인증**이 필요합니다. 인터넷 전화(VoIP)·가상번호·유선전화 번호는 받지 않고, 한 번호로 최대 3개 계정까지만 만들 수 있습니다.
본인 휴대폰 번호로 다시 시도하세요. 오늘 안에 해결이 안 되면 **Gemini**로 실습하면 됩니다(모든 Basic 단계가 Gemini로도 됩니다).

### 회사 노트북에서 AI 사이트가 막혀 있어요 {#q-blocked}

1. 휴대폰 핫스팟으로 바꿔도 회사 보안 프로그램이 막을 수 있습니다 — 회사 규정을 어기면서 우회하지 마세요.
2. 개인 노트북이 있으면 그것을 씁니다.
3. 없으면 옆 사람과 **한 화면으로 페어**(드라이버·내비게이터)를 합니다. 엑셀 단계는 내 노트북에서 해도 됩니다.

### 회사 Google 계정으로 Colab·Gemini가 안 열려요 {#q-workspace}

회사 Google Workspace 계정은 관리자가 Colab·Gemini를 꺼 둔 경우가 많습니다. **개인 Google 계정**으로 로그인하세요.
Colab의 AI 기능은 만 18세 이상 개인 계정에서만 보입니다.

### 과정 사이트가 안 열리거나 글꼴이 이상해요 {#q-site}

글꼴(Noto Sans KR)은 Google Fonts에서 받아 오는데, 회사 망에서 막히면 기본 글꼴로 보입니다 — 내용은 같으니 그대로 쓰면 됩니다.
사이트 자체가 안 열리면 강사가 오픈채팅·USB로 파일을 나눠 드립니다.

## AI 도구

### ChatGPT에 파일이 더 안 올라가요 (업로드 한도) {#q-upload-limit}

ChatGPT **무료** 계정은 파일 업로드가 **하루 3개**입니다. 오늘 실습은 그보다 많이 올리므로 **Claude 또는 Gemini**로 바꾸세요.
ChatGPT를 꼭 쓰려면 강사 공용 프로젝트(초대 링크) 또는 유료 개인 계정을 씁니다.

### 파일 업로드가 실패해요 (크기·형식) {#q-upload-fail}

| 도구 | 한도(2026-09-26 확인) | 안 될 때 |
|---|---|---|
| Claude | 파일당 30MB | 과정 파일은 모두 1MB 미만이라 크기 문제는 드뭅니다. 로그인 상태를 확인하세요 |
| Gemini 앱 | 한 번에 10개, 파일당 100MB | `.xlsx`가 안 되면 같은 내용의 `.csv`를 올립니다 |
| ChatGPT 무료 | 하루 3개 | 다른 도구로 바꿉니다 |

`.md` 파일이 '지원하지 않는 형식'으로 나오면, 파일을 메모장으로 열어 전체 복사(++ctrl+a++ → ++ctrl+c++)한 뒤 입력창에 붙여 넣어도 됩니다.

### AI가 준 인용문이 원문에서 안 찾아져요 {#q-quote}

1. 인용 전체 대신 **중간의 짧은 단어 4–5개**로 ++ctrl+f++ 를 다시 합니다(줄바꿈·따옴표 차이를 피하기 위해).
2. 그래도 없으면 AI가 문장을 바꿨거나 지어낸 것입니다. `01_보고서신호`의 검증 칸(G열)에서 **✘**를 고르고 **P1-1c**(인용 재확인)로 다시 묻습니다. 다시 물은 결과는 그 행의 메모 칸(H열)에 적습니다(예: `재확인 ✔` 또는 `✘ — 지어낸 인용`).
3. 이것은 실패가 아니라 **발견**입니다. 오늘 실습의 목적이 바로 이것을 찾는 것입니다.

### AI가 앞에서 정한 형식을 잊거나, 같은 질문에 답이 매번 달라요 {#q-context}

- 대화가 길어지면 AI는 앞부분을 놓칩니다(작업 책상이 넘침). 일이 바뀌면 **새 채팅**을 엽니다.
- AI는 '그럴듯한 다음 말'을 고르는 방식이라 같은 질문에도 답이 조금씩 다릅니다. 그래서 **근거(인용·위치·코드)**를 함께 받고 확인합니다.
- 긴 작업을 이어 가야 하면 `지금까지 정한 조건과 결론을 짧게 정리해 줘` → 새 채팅에 그 요약을 붙여 넣고 시작합니다.

### AI 답의 표를 엑셀에 붙이면 한 칸에 몰려요 {#q-paste}

AI 화면의 '복사' 버튼은 표를 글자(마크다운)로 복사할 때가 많습니다.

1. 표를 **마우스로 끌어 선택**한 뒤 ++ctrl+c++ 를 누르고 엑셀에 붙여 넣습니다.
2. Gemini는 표 아래 **Sheets로 내보내기**를 써도 됩니다.
3. 그래도 안 되면 AI에게 `탭으로 구분된 표로 다시 줘`라고 한 뒤 붙여 넣습니다.

### 화면의 모델 이름이 안내와 달라요 {#q-model-names}

정상입니다. 모델 이름과 메뉴는 자주 바뀌어서(개강일에도 바뀝니다) 안내에는 **기본 모델 / 추론 모델**로만 적었습니다.
먼저 기본 모델로 하고, 결과가 이상하거나 조건이 복잡하면 추론 모델로 바꿔 비교하세요.

## 엑셀

### CSV를 열면 한글이 깨져요 {#q-csv}

과정 CSV는 UTF-8(BOM 포함)이라 보통 바로 열립니다(1일차 Step 1의 연습 파일 `d1_encoding_test.csv`만 일부러 BOM 없이 저장해 깨지게 했습니다). 깨지면:

1. 가능하면 같은 내용의 **`.xlsx`** 파일을 씁니다.
2. CSV를 써야 하면 엑셀 빈 통합 문서에서 **데이터** 탭 → **텍스트/CSV에서**를 누릅니다.
3. 파일을 고른 뒤 '파일 원본'을 **65001: 유니코드(UTF-8)**로 바꾸고 **로드**를 누릅니다.
4. 내가 CSV로 저장할 때는 파일 형식에서 **CSV UTF-8(쉼표로 분리)**을 고릅니다(그냥 'CSV'로 저장하면 다른 프로그램에서 한글이 깨질 수 있습니다).

### XLOOKUP이 없어요 (#NAME?) {#q-xlookup}

Excel 2019·2016 이하에는 XLOOKUP이 없습니다. [실습 B Step 5의 대안 수식](day1/lab-b.md#xlookup-alt)(INDEX·MATCH 또는 VLOOKUP)을 쓰면 결과가 같습니다.
버전 확인: **파일** → **계정** → **Excel 정보**. 웹용 Excel(office.com)에는 XLOOKUP이 있습니다.

### 표 만들기(++ctrl+t++)가 안 되거나, 표 이름을 바꾸는 곳을 모르겠어요 {#q-table}

1. 데이터가 있는 셀(예: A2)을 **하나** 클릭한 뒤 ++ctrl+t++ 를 누릅니다(빈 셀이나 여러 셀을 고른 상태면 범위가 이상해집니다).
2. '표 만들기' 창에서 **머리글 포함**을 체크하고 **확인**.
3. 표 안을 클릭하면 위쪽에 **테이블 디자인** 탭이 생깁니다 → 맨 왼쪽 **표 이름** 칸에서 바꿉니다(예: `tbl_buyers`).
4. 이미 표인 범위에서 ++ctrl+t++ 를 누르면 아무 일도 일어나지 않습니다 — 이미 표라는 뜻입니다.

### 피벗 숫자가 AI 숫자와 달라요 {#q-pivot-vs-ai}

**정상이고, 오늘 실습의 핵심입니다.** 둘 다 틀릴 수 있습니다. 아래 순서로 원인을 찾아 `03_EDA`에 적습니다.

1. **분모**: AI는 몇 행을 읽었나? 엑셀 표는 몇 행인가(`=ROWS(tbl_buyers)`)?
2. **중복**: 같은 `buyer_id`가 두 번 세어지지 않았나?
3. **숫자가 아닌 칸**: 연체일이 글자인 칸을 AI는 어떻게 처리했나(0으로? 빼고?), 엑셀은 '확인필요'로 따로 뺐다.
4. **결제조건 매핑**: AI의 매핑표와 내 `00_코드표`가 같은가? '미분류'를 어디에 넣었나?
5. **정의**: '연체 = 연체일 > 0'으로 같은가?

그다음 AI에게 `엑셀에서는 ○○이 △△로 나왔다. 네 계산과 다른 이유를 코드로 확인해 줘`라고 묻습니다.

### 피벗에서 새 열이 안 보이거나, 평균이 안 돼요 {#q-pivot}

- 새 열이 필드 목록에 없으면: 피벗 안 클릭 → **피벗 테이블 분석** → **새로 고침**. 그래도 없으면 **데이터 원본 변경** → `tbl_buyers`.
- 값이 '개수'로만 나오면: 값 ▼ → **값 필드 설정** → **평균**. 글자가 섞인 열은 엑셀이 '개수'를 기본으로 잡습니다. 연체일은 원본 `max_dpd_days` 대신 **`dpd_num`**을 씁니다.

### '피벗 테이블 보고서는 겹칠 수 없습니다'가 떠요 {#q-pivot-overlap}

피벗이 커지면서 아래쪽 피벗과 겹친 것입니다. 피벗 안을 클릭 → **피벗 테이블 분석** → **피벗 테이블 이동** → 더 아래 빈칸을 고릅니다.
템플릿 `04_피벗`은 피벗 자리를 A22 · A42 · A62로 넉넉히 띄워 두었습니다.

### AI 표를 붙였더니 템플릿 색이 사라지거나 열이 어긋나요 {#q-paste-format}

- 색: 붙일 칸을 마우스 오른쪽 버튼으로 누르고 **붙여넣기 옵션 → 대상 서식에 맞추기**를 고릅니다. 이미 붙였다면 ++ctrl+z++ 후 다시 붙입니다.
- 열: 프롬프트(P1-1·P1-3)는 템플릿과 같은 열 순서로 표를 만들게 되어 있습니다. 표의 **첫 데이터 줄부터**(머리글 줄은 빼고) 선택해 붙이고, 머리글 줄까지 붙었으면 그 줄만 지웁니다. 그래도 열이 어긋나면 각 프롬프트의 '흔한 실패와 재질문' 문장으로 열 순서를 다시 요청합니다 — [실습 A Step 2 ③](day1/lab-a.md#step2) 참고.

### 파일을 열면 노란 띠(제한된 보기)가 떠요 {#q-protected-view}

인터넷에서 받은 파일이라 엑셀이 읽기 전용으로 연 것입니다. **편집 사용**을 누르세요. 과정 엑셀 파일에는 매크로가 없습니다.

### 엑셀 '데이터 분석'(Analyze Data)에 한국어로 물으면 안 돼요 {#q-analyze-data}

이 기능은 한국어 질문을 지원하지 않습니다. 오늘은 피벗 테이블을 직접 만들고, 질문은 Claude·Gemini에게 합니다.

## Orange

### Orange 설치가 막혀요 {#q-orange-install}

Windows 설치 파일은 관리자 권한 없이 설치됩니다. 그래도 막히면 같은 다운로드 페이지의 **포터블(zip)** — 압축만 풀고 실행합니다.
그것도 안 되면 강의장 USB의 포터블판을 쓰거나, 오늘은 Orange 없이 엑셀 차트로 진행해도 됩니다(Orange는 선택). 자세한 순서: [사전 준비 → Orange](setup.md#orange).

### Orange Box Plot에 결제방식 그룹이 안 보여요 {#q-orange-type}

열이 글자(text)로 읽혔기 때문입니다. **File** 위젯을 더블클릭 → 열 목록에서 `payment_method`의 Type을 **categorical**로 바꾸고 → **Apply**.
`dpd_num`이 숫자(numeric)로 잡혔는지도 확인합니다.

## Colab (🟣 Challenge)

### Colab 차트의 한글이 □□로 나와요 {#q-colab-font}

1. 노트북 맨 위쪽의 **한글 글꼴 칸**을 실행했는지 확인합니다(▶).
2. 글꼴 칸을 실행한 뒤 **차트 칸을 다시 실행**합니다.
3. 그래도 □이면 메뉴 **런타임** → **세션 다시 시작** → 맨 위 칸부터 순서대로 다시 실행합니다.

### SEC 요청이 403 Forbidden으로 막혀요 {#q-sec-403}

SEC는 요청마다 **누가 보내는지(User-Agent: 이름 + 이메일)**를 밝히라고 요구하고, 없으면 403으로 막습니다. 초당 10회 넘게 요청해도 막힙니다.

1. 노트북 **A-1** 칸의 User-Agent에 **영문 이름과 이메일**을 넣습니다(한글은 오류가 납니다). 예: `Gildong Hong gildong.hong@mycompany.com` — 예시 주소(example.com) 그대로면 노트북이 멈춥니다.
2. 몇 초 기다렸다 다시 실행합니다(강의장 전원이 같은 인터넷 주소를 씁니다).
3. 계속 막히면 강사 추출본 `real_buyers_ratios.csv`로 대조합니다.

직접 코드를 쓴다면: `requests.get(url, headers={"User-Agent": "Gildong Hong gildong.hong@mycompany.com"})`

### Colab에서 패키지 오류가 나거나 파이썬 버전이 달라요 {#q-colab-runtime}

- `pip install -U`(업그레이드)는 하지 않습니다. 기본 설치된 버전으로 충분합니다.
- 오류가 계속되면 메뉴 **런타임** → **런타임 유형 변경**에서 런타임 버전을 강사가 안내한 버전으로 고른 뒤, 맨 위 칸부터 다시 실행합니다.

### Colab에 올린 파일이 사라졌어요 {#q-colab-files}

Colab 왼쪽 폴더에 올린 파일은 **세션이 끝나면 지워집니다**(오래 쉬거나 런타임을 다시 시작했을 때). 파일을 다시 올리고 맨 위 칸부터 다시 실행하세요.
노트북 자체는 **파일** → **Drive에 사본 저장**으로 저장해 둡니다.

## 데이터 · 제출

### 실수로 회사 실데이터를 AI에 올렸어요 {#q-leak}

1. 그 대화를 바로 **삭제**합니다.
2. 강사·도우미에게 알립니다(비난하지 않습니다. 기록만 합니다).
3. 가상 데이터로 바꿔 계속합니다. 다음부터는 [익명화 체크리스트](setup.md#byod)를 먼저 봅니다.

### 압축을 풀었는데 보고서 파일이 안 보여요 {#q-zip}

1. 보고서 발췌(`halden_fictional_annual_report.md` · `irobot.md` · `plug_power.md` 등)는 `D1` 폴더 안의 **`reports`** 폴더에 있습니다.
2. `D1` 폴더 안에 또 `D1` 폴더가 있으면(두 겹), 안쪽 `D1` 폴더를 바탕화면으로 끌어다 놓고 빈 바깥 폴더는 지웁니다.
3. zip 파일을 더블클릭해 안을 들여다보기만 한 상태에서 엑셀 파일을 열면 임시 폴더에서 열려, 저장한 내용이 사라질 수 있습니다. 꼭 마우스 오른쪽 버튼 → **모두 압축 풀기**로 푼 뒤 `D1` 폴더의 파일을 엽니다.

순서는 [Day1 → 파일 받기](day1/index.md#files)에 있습니다.

### 보고서 발췌(.md) 파일은 어떻게 여나요? {#q-md}

글자만 들어 있는 파일입니다. 파일을 마우스 오른쪽 버튼으로 누르고 **연결 프로그램 → 메모장**(Mac: **다음으로 열기 → 텍스트 편집기**)을 고르거나, 크롬 창에 끌어다 놓으면 열립니다.
사이트에서 눌렀을 때 화면에 글자만 뜨면 **마우스 오른쪽 버튼 → 다른 이름으로 링크 저장**으로 받습니다.

### 제출 파일 이름은 어떻게 쓰나요? {#q-submit}

`d1_end_eda__T{조}-{번호}.xlsx` — 밑줄 **두 개**, 대문자 **T**, 번호는 **두 자리**. 예: 2조 7번 → `d1_end_eda__T2-07.xlsx`.
제출 순서는 [Day1 → 산출물과 제출](day1/index.md#submit)에 있습니다.
