## 1. 시트별 구조

통합 문서에는 시트가 4개(요약 + 지역 3개)입니다. 지역 시트 3개의 레이아웃은 같습니다.

### 1-1. 지역 시트 공통 레이아웃

| 항목 | 내용 |
|---|---|
| 제목 줄 | 1~2행, `A1:K2` 병합. "2026년 9월말 미수금 현황 (단위: 천원)" |
| 머리글 | **2단, 3~4행**. `A3:A4`(담당) · `B3:B4`(바이어) · `C3:C4`(국가) · `D3:D4`(결제조건) · `E3:E4`(인보이스 번호) · `F3:F4`(선적일) · `G3:G4`(만기일) · `K3:K4`(메모)는 세로 병합. `H3:J3`은 "금액"으로 가로 병합, 4행에 H 원화(천원) · I 외화 · J 통화 |
| 데이터 시작 | 5행부터. 열 A~K (담당 · 바이어 · 국가 · 결제조건 · 인보이스 번호 · 선적일 · 만기일 · 원화(천원) · 외화 · 통화 · 메모) |
| 구조 | **담당자 블록 반복**: 데이터 행들 → `○○ 소계` 행(`=SUM(H…)`) → 빈 줄 → 다음 담당자 블록 |
| 맨 아래 | 빈 줄 1개 → `합계` 행(`=소계 행들의 합`, 예: `=H23+H51+…`) |
| 기타 | 숨김 시트·숨김 행/열·필터·틀 고정 없음. 소계 행은 굵은 글씨 |

### 1-3. 요약 시트

- 1~2행 `A1:D2` 병합 제목 "2026년 9월말 미수금 현황 — 지역별 요약 (단위: 천원)", 3행 빈 줄, **머리글은 4행**(지역 · 건수 · 원화(천원) · 비고).
- 5~7행 지역별 줄: 건수는 `=COUNTIF('시트'!E5:E…,"INV*")`, 금액은 `='시트'!H합계행`(각 시트의 합계 셀을 그대로 가져옴).
- 8행 `합계`(`=SUM(B5:B7)`, `=SUM(C5:C7)`), 9행 빈 줄, 10행 주석 "※ 기준일 2026-09-30 · 영업팀 취합본(시트별 담당자가 직접 입력)".

### 1-4. 구조 때문에 생기는 주의점

- 소계·합계·빈 줄이 데이터와 같은 열(A·H)에 섞여 있어 피벗·`read_excel`에 그대로 쓰면 소계가 이중 집계됩니다. 소계 행의 식별자는 A열 문자열 `… 소계`뿐입니다.
- 머리글이 2단 병합이라 한 줄 머리글로 읽으면 `금액` 아래 열 이름(원화·외화·통화)이 `Unnamed`로 나옵니다.
- 데이터 행에 지역·팀 정보가 따로 없고(시트명과 담당 열 이름에만 있음), 시트를 합치면 지역 열을 만들어 줘야 합니다.

### 2-1. 이상 없음으로 확인한 점

- 소계 행의 `SUM` 범위(블록 경계)는 모두 맞습니다. 즉 **수식은 맞고 입력이 틀립니다**(Q-01, Q-02).
- 합계 행(`=소계의 합`)과 요약 시트의 연결 셀(`='시트'!H…`)도 올바른 셀을 가리킵니다.
- 데이터 행의 빈 셀 없음(담당·바이어·국가·결제조건·인보이스·날짜·금액·외화·통화 모두 채워짐). 메모만 선택 입력.
